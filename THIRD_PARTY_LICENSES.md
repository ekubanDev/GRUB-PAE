## Note on Upstream Remote

This repository maintains an `upstream` remote pointing at `https://github.com/enatega/food-delivery-multivendor` to allow security patches from the original frontend modules to be pulled forward. The proprietary Enatega API server is not included in the upstream repository and is not used in this project.
